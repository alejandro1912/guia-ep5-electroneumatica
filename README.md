# Guía interactiva EP5 — Sistemas Electroneumáticos Industriales

Sitio estático de una sola página, en español, con una ruta de apoyo para resolver la Evaluación Parcial 5 de PAI1104 usando FluidSIM.

## Abrir

Abre `index.html` en un navegador, o sirve esta carpeta con cualquier servidor estático (por ejemplo, `python -m http.server 8000`). No requiere dependencias ni compilación.

## Incluye

- Pasos para analizar, diseñar, implementar, probar y entregar el circuito.
- Demostración interactiva de la condición AND con dos pulsadores.
- Lista de verificación con avance guardado en el navegador.
- Rúbrica y ponderaciones reproducidas de la pauta entregada.
- Diseño adaptable e impresión/guardado como PDF.

## Nota técnica

El PDF pide el retorno del cilindro y una explicación del circuito, pero el texto no fija un único mando de retorno ni incluye los enunciados de las tres preguntas de fundamentación. La guía identifica esos límites y presenta el pulsador de retorno como propuesta didáctica, que debe ajustarse a lo que indique el docente. La AND de dos pulsadores no es un dispositivo de seguridad bimanual certificado.

## Publicación

El proyecto está preparado para GitHub Pages como sitio estático. Para publicar, sube `index.html` y este README a un repositorio y activa Pages desde la rama principal, carpeta raíz.
